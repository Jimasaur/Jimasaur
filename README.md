## Start with these three

### 1. [Voice Agents](https://github.com/Jimasaur/voice_agents)
**Workflow demos · Python / FastAPI / OpenAI Realtime**

Real-time voice demos for healthcare operations and service-desk intake, backed by synthetic SQLite workflows. Start here for the user experience and a concrete example of connecting voice interactions to application tools.

### 2. [Athena](https://github.com/Jimasaur/athena-public)
**Integration architecture · Ruby on Rails / Twilio / OpenAI Realtime**

A voice-agent control-plane prototype connecting live calls, transcripts, tool activity, and approval workflows. Explore the [architecture](https://github.com/Jimasaur/athena-public/blob/main/docs/architecture.md) and [demo walkthrough](https://github.com/Jimasaur/athena-public/blob/main/docs/demo_walkthrough.md) for the integration design and human-review flow.

### 3. [Cognitive Council](https://github.com/Jimasaur/cognitive-council)
**Inspectable agent behavior · Python / FastAPI**

A local, deterministic decision-runtime prototype with modular signals, approval state, structured receipts, and regression fixtures. The default example runs without an API key; the [runtime contract](https://github.com/Jimasaur/cognitive-council/blob/main/docs/runtime-api.md) shows how results can be reviewed and tested.
